Padam Akaun Murid?

Tindakan Pentadbir Utama (Super Admin)

Nama Murid: ...

warning

Lantik Sebagai Guru Sains?

Tindakan Pentadbir Utama (Super Admin)

Anda akan melantik pengguna berikut sebagai Guru Sains ARSelNel:

Nama Pengguna: ...
Alamat E-mel: ...
info

Guru yang dilantik akan mempunyai akses ke Papan Pemuka Pentadbir CMS untuk mengurus nota, video, kuiz, permainan, dan melihat rekod pembelajaran murid. Guru tidak boleh memadam murid atau melantik guru lain.

remove_moderator

Batalkan Pelantikan Guru?

Tindakan Pentadbir Utama (Super Admin)

Anda akan membatalkan peranan guru bagi pengguna berikut:

Nama Guru: ...
Alamat E-mel: ...
lock_reset

Akses ke Papan Pemuka Pentadbir CMS akan ditarik balik serta-merta. Pengguna ini akan dikembalikan kepada akaun Murid tanpa memadam rekod pembelajarannya.
